# Customer Shopping Behavior Analysis

## Overview

This project analyzes customer shopping behavior using transactional data from **3,900 purchases** across various product categories. The objective is to identify spending patterns, customer segments, product preferences, discount behavior, and subscription trends to support business decision-making.

## Dataset

- **Rows:** 3,900
- **Columns:** 18
- **Missing Data:** 37 values in the `Review Rating` column

### Key Features

- **Customer demographics:** Age, Gender, Location, Subscription Status
- **Purchase details:** Item Purchased, Category, Purchase Amount, Season, Size, Color
- **Shopping behavior:** Discount Applied, Promo Code Used, Previous Purchases, Frequency of Purchases, Review Rating, Shipping Type

## Tools & Technologies

- **Python / pandas** — data loading, cleaning, EDA, and feature engineering
- **PostgreSQL** — database integration and SQL business analysis
- **Power BI** — interactive dashboard and data visualization

## Project Steps

### 1. Data Loading & Exploration

The dataset was imported into Python using pandas. Initial exploration included `df.info()` for structure, `df.describe()` for summary statistics, and null-value checks.

### 2. Data Cleaning

- Missing `Review Rating` values were imputed using the median rating of each product category.
- Columns were renamed to `snake_case`.
- `discount_applied` and `promo_code_used` were checked for redundancy.
- `promo_code_used` was dropped after the consistency check.

### 3. Feature Engineering

- Created `age_group` by grouping customer ages.
- Created `purchase_frequency_days` from purchase data.

### 4. PostgreSQL Integration

The cleaned pandas DataFrame was connected to PostgreSQL and loaded into the database for SQL analysis.

### 5. SQL Business Analysis

The project answers these business questions:

1. **Revenue by Gender** — Compared total revenue generated by male and female customers.
2. **High-Spending Discount Users** — Identified customers who used discounts but spent above the average purchase amount.
3. **Top 5 Products by Rating** — Found products with the highest average review ratings.
4. **Shipping Type Comparison** — Compared average purchase amounts between Standard and Express shipping.
5. **Subscribers vs. Non-Subscribers** — Compared average spend and total revenue by subscription status.
6. **Discount-Dependent Products** — Identified the five products with the highest percentage of discounted purchases.
7. **Customer Segmentation** — Classified customers into New, Returning, and Loyal segments based on purchase history.
8. **Top 3 Products per Category** — Listed the most purchased products within each category.
9. **Repeat Buyers & Subscriptions** — Checked whether customers with more than five purchases were more likely to subscribe.
10. **Revenue by Age Group** — Calculated total revenue contribution of each age group.

## How to Run

### Python

1. Install Python.
2. Install pandas.
3. Place the dataset in the `data/` folder.
4. Run the Python analysis script.

```bash
pip install pandas
python python/customer_shopping_behavior_analysis.py
```

### PostgreSQL

1. Create a PostgreSQL database.
2. Load the cleaned customer data.
3. Run the SQL queries from the `sql/` folder.
4. Review the results for the business questions.

### Power BI

1. Open the `.pbix` Power BI file.
2. Connect or refresh the project data if required.
